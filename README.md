# Data_Science_Research_Project

This project so far only has the reproduction code for the Ryan et al. (2025) work. The folder "Reproduction_Code" mimics the local directory so just downloading the entire folder as it is then changing the name of the folder "Reproduction_Code" to just "Reproduction Code" will help you to run the code sequentially inside.

The resulting files from the training set of the models can be found in the "results" folder. Similarly, the resulting files from the test set can be found in the "models" folder. "figures" folder nwo only has the feature importance figures. On the same note, raw and processed data can both be found in the same directory as the code.

*New Edit*
This repository now carries the Italian extension of the Australian reproduction with a slightly different aim. The folder "final_report" details everything about the project. The folder "New Code" on the other hand will help you reproduce the Italian context of this project. This folder also mimics the local repository entirely so downloading it in the same directory as "Reproduction_Code", then running the R scripts in the sequential order as per the prefix of their name, but first ensuring the right file path should work just fine. 

All the original datasets used in this project can be found in the "data" folder, alongside cleaned, processed, and train/test data. The rest of the resulting files can be found in the other sub directories inside "New Code".
